TABUNGAN RIKO & LIA — ONLINE (paling mudah)

A. PASANG (sekali saja, ±5 menit)
1. Buka github.com -> New repository -> beri nama "tabungan" -> pilih PUBLIC -> Create.
2. Klik "uploading an existing file", tarik 2 file: index.html dan data.json -> Commit changes.
3. Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder / (root) -> Save.
4. Tunggu 1-2 menit. Alamat aplikasi:  https://USERNAME.github.io/tabungan/

B. HUBUNGKAN PENYIMPANAN ONLINE (sekali per perangkat)
1. Buka alamat aplikasi -> klik tombol "GitHub" di pojok atas.
2. Klik "Buka GitHub": formulir kunci akses sudah terisi.
   Pilih "Only select repositories" -> pilih repo "tabungan" -> klik Generate token -> SALIN kuncinya.
3. Tempel kunci di aplikasi -> "Simpan & tes". Jika berhasil muncul "Tersimpan di GitHub".

C. PERANGKAT LAIN (HP Lia, dll.) — tanpa mengulang langkah B
1. Di perangkat yang sudah terhubung: GitHub -> "Bagikan tautan sambung".
2. Kirim tautannya lewat chat PRIBADI (jangan grup/media sosial; tautan berisi kunci akses).
3. Buka tautan di perangkat lain -> "Hubungkan". Selesai.

CATATAN
- Repo publik: data.json bisa dibaca siapa saja yang tahu alamatnya.
- Refresh halaman sebelum mengedit di perangkat lain (data tidak real-time).
- Kunci hilang/bocor? Hapus di GitHub (Settings -> Developer settings -> Fine-grained tokens), buat yang baru.
